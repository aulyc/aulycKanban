
# 思源笔记看板插件

这是一个为思源笔记设计的简洁高效的任务看板插件。插件以五元组分类的为基础，专注于可视化任务整理与管理，提升你的专注与效率。

## 🍀 主要功能

- 五大任务列：
    - 🔄 周期性任务
    - 🔥 重要紧急
    - ⭐ 重要不紧急
    - ⚡ 不重要紧急
    - 💤 不重要不紧急
- 任务添加、删除
- 任务完成状态切换
- 双击任务内容快速编辑
- 拖拽任务在不同列之间移动
- 数据持久化保存
- 可导出当前看板到所选笔记本文档
- 支持自动同步每次变更到选定笔记
- 简洁响应式界面，原生适配深色/浅色主题

## ⚡ 性能优化

本插件采用多项性能优化技术，确保在大量任务下依然流畅：

- **虚拟滚动**：每列只渲染可见的 30 个任务，大幅减少 DOM 节点
- **事件委托**：使用容器级事件监听，避免为每个任务绑定事件
- **增量更新**：操作时只重新渲染变化的列，不重建整个看板
- **RAF 优化**：使用 requestAnimationFrame 优化渲染时机
- **数据缓存**：缓存排序结果，避免重复计算

✅ **实测性能**：
- 500 任务：流畅无卡顿
- 1000 任务：依然保持良好性能
- 2000+ 任务：可正常使用

## 🚀 安装方法

1. 通过本地插件管理页面导入本插件的zip。
2. 启用插件后，右上角顶部工具栏出现“看板”按钮，点击可快速打开/关闭任务看板窗口。

## ⌨️ 快捷键

- **Option+Command+B (Mac)** / **Alt+Ctrl+B (Windows)** - 打开/关闭看板

> 💡 快捷键已优化避免与思源笔记内置功能冲突

## ⚠️ 已知说明/限制

- 当前只提供单一固定结构的看板（暂不支持多看板、标签、截止日期、优先级、模板、Scrum等）
- **性能优化**：已优化支持 **1000+ 任务**（使用虚拟滚动、事件委托、增量渲染等技术）
- 同步功能仅在配置后生效
- 仅在 macOS 的思源笔记中进行过测试，未针对移动端测试
- UI操作主要为鼠标/触控

## 📦 常见问题

### Q: 无法看到看板按钮怎么办？
A: 请确认插件已正确安装并启用。理论上顶部工具栏应有“看板”图标。若无，请重启思源笔记后重试。

### Q: 看板数据丢失如何恢复？
A: 插件每次变更均自动保存（本地数据存储），如有同步笔记功能也可到文档中查找历史版本。

### Q: 如何升级？
A: 下载最新版本覆盖原插件文件，并在插件管理器中重载即可。数据不会丢失。
